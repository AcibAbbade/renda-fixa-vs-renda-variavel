# Renda Fixa x Renda Variável

## Descrição do Projeto
Este projeto tem como objetivo criar um miniguia de estudo sobre os conceitos de renda fixa e renda variável, utilizando o NotebookLM como ferramenta de apoio à aprendizagem.

## Objetivos de Estudo
- Compreender os conceitos de renda fixa e renda variável.
- Identificar diferenças entre risco, retorno e liquidez.
- Reconhecer exemplos de investimentos no Brasil.
- Relacionar os conceitos ao perfil do investidor.

## Metodologia
Foram utilizadas fontes abertas e institucionais. A IA foi empregada para gerar respostas, que foram analisadas criticamente e comparadas com as referências.

## Fontes
- CVM – Cartilha do Investidor  
- Banco Central do Brasil – Educação Financeira  
- B3 – O que é renda fixa e renda variável
